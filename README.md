# ExplainableAI-BasedBrainTumorDetectionusinganEnhancedCNNArchitecture
An Explainable AI-based brain tumor detection system using an enhanced CNN architecture with Batch Normalization, CBAM, and Dropout. The framework classifies MRI images into Glioma, Meningioma, Pituitary Tumor, and No Tumor categories and uses Grad-CAM to provide visual explanations for model predictions.
